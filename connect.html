Connect TikTok

For the channel owner. This step lets blackbabata Studio upload the owner's own videos to the owner's own TikTok account.

What you will be asked to allow

  • user.info.basic - read the account's display name and avatar, so the tool can show which account will receive the video.
  • video.upload - send a video to the account's TikTok inbox as a draft. The account holder reviews and publishes it in the TikTok app.

What happens next

  1. TikTok asks you to log in and approve the permissions above.
  2. TikTok sends you back to the result page, which shows a one-time authorization code.
  3. You paste that code into the local blackbabata Studio tool, which exchanges it for an access token stored only on your own computer.

You can withdraw access at any time in the TikTok app's settings. See the Privacy Policy.
